Anti Sleep Alarm

Keep the driver awake. Stop the wheel when it matters.

An Arduino UNO wheel-robot prototype that watches eye closure with an IR blink sensor, sounds a piezo warning, and cuts motor power through a relay.

View Firmware Watch Demos

Overview

A focused drowsiness-response prototype

Built as an academic robotics project and packaged as a clean portfolio repository. The physical demo uses spectacles-mounted IR sensing and a hobby motor stand-in for vehicle motion.

System Architecture

Sense → Decide → Warn → Stop

The blink sensor feeds the Arduino state machine. Warning goes to the buzzer; emergency action opens the motor path through the relay.

  1. 01Blink SensorIR TX/RX on spectacles
  2. 02Arduino UNOState-machine firmware
  3. 03Piezo BuzzerAudible warning on D12
  4. 04Relay + Motor9V load switched on D13

Detection Logic

Four states. Clear thresholds.

Final firmware matches the original AIM / Arduino timing: warn at 3 seconds, stop at 4 seconds. Eye-open resets the system.

How to run

Upload, wire, test

  1. Install Arduino IDE and open anti_sleep_alarm.ino
  2. Select Arduino UNO + COM port, then upload
  3. Wire sensor → D2, buzzer → D12, relay → D13
  4. Power motor through relay COM/NC with 9V battery
  5. Hold eye closed: ~3 s buzzer, ~4 s motor stop
  6. Optional Serial Monitor at 115200 baud

Safety

Prototype boundaries

  • Academic / portfolio prototype only — not automotive certified
  • Do not connect to a real vehicle braking system
  • Use a low-voltage hobby motor for demonstration only
  • Never power the motor from an Arduino GPIO pin
  • Verify relay polarity and battery wiring before power-up
